## Что такое нормализация вектора

Нормализация — приведение вектора к некоторому «стандартному виду».
В контексте ML/эмбеддингов наиболее распространена **L2-нормализация**:
каждый компонент делится на длину (Euclidean norm) вектора.

Формула:
  ||v|| = sqrt(v1² + v2² + ... + vn²)
  v_normalized[i] = v[i] / ||v||

Результат: вектор той же направленности, но длиной 1 (unit vector).

## Альтернативы

| Тип | Формула | Когда применяется |
|-----|---------|-------------------|
| L2 (Euclidean) | v / sqrt(sum(v²)) | ML, embeddings, cosine similarity |
| L1 (Manhattan) | v / sum(\|v\|) | Разреженные данные, robust statistics |
| Min-Max | (x - min) / (max - min) | Приведение к [0, 1], нейросети |

## Решение

Выбираем **L2-нормализацию** — стандарт для ML-задач, к которым относится ModelWorker
(согласно description: "Vector operations: normalize, dot product, cosine similarity").

## Сигнатура

Предлагается:

    Result ModelWorker::normalize(const std::vector<double>& v) const;

Возвращает `Result` — структурированный ответ. При ошибке (пустой вектор, нулевой вектор)
возвращает `Result::fail(...)`, при успехе — `Result::ok(...)` со строковым представлением
нормализованного вектора (для совместимости с текущим CLI-выводом).

**Альтернативы, которые рассмотрели:**
- `std::vector<double> normalize(...)` — не подходит, потому что не может выразить ошибку без throw.
- `Result normalize(...)` с `Result` внутри — усложняет API, для CLI достаточно строки.

## Валидация

Некорректные случаи:
1. **Пустой вектор** — нечего нормализовать. `fail("Empty vector")`.
2. **Нулевой вектор** — длина 0, деление на ноль. `fail("Cannot normalize zero vector")`.
3. **Невалидные числа** — обрабатывается на этапе парсинга (в `parseVector`).

## Открытые вопросы для команды

- Достаточно ли L2, или нужна опция выбора нормы (L1/L2)?
- Формат вывода: строка `"0.6,0.8"` или JSON `[0.6, 0.8]`?
